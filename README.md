# LBank KOC & BD Stratejik İtiraz Karşılama Portalı (Çok Dilli / Multi-Language)

## 🌍 Desteklenen Diller (6 Dil)

Site, sağ üstteki dil menüsünden veya doğrudan URL parametresiyle anında ve sayfa yenilenmeden seçilebilir:

1. 🇬🇧 **English (en)** — Global Kripto Standardı (`?lang=en`)
2. 🇹🇷 **Türkçe (tr)** — Orijinal Metinler (`?lang=tr`)
3. 🇮🇳 **हिन्दी / Hindi (hi)** — Hindistan Kripto Pazarı (`?lang=hi`)
4. 🇵🇰 **اردو / Urdu (ur)** — Pakistan Kripto Pazarı (`?lang=ur`)
5. 🇹🇭 **ภาษาไทย / Thai (th)** — Tayland Kripto Pazarı (`?lang=th`)
6. 🇮🇩 **Bahasa Indonesia (id)** — Endonezya Kripto Pazarı (`?lang=id`)
